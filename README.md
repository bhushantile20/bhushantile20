## 🎯 About Me

💻 I am a developer passionate about **Machine Learning, Data Engineering, Cloud Computing, and MLOps**.

My goal is to build reliable, scalable, and automated machine learning systems - from raw data ingestion and feature engineering to model training, deployment, monitoring, and continuous improvement.

- 🤖 Learning and implementing end-to-end machine learning workflows.
- ⚙️ Building automated ML pipelines with Python, MLflow, and Databricks.
- 🐳 Exploring containerization, model serving, and deployment with Docker.
- 🔄 Implementing CI/CD workflows using GitHub Actions and Databricks Asset Bundles.
- ☁️ Working with cloud platforms, data pipelines, and modern analytics architectures.
- 📚 Continuously improving my technical skills, communication, and engineering practices.

**My mindset:** Learn deeply. Build consistently. Automate intelligently. Deploy confidently.
